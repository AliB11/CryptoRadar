# رادارِ بازار — CryptoRadar

ترمینال سیگنال ارزهای دیجیتال، کاملاً سمت‌مرورگر: تحلیل تکنیکال ۱۰۰ دارایی برتر، قطب‌نمای لنگر بیت‌کوین، واگرایی RSI، قفل هم‌گرایی هشت‌عاملی، بک‌تست walk-forward، پرتفوی و هشدار قیمت.

Live: [crypto-radar-five.vercel.app](https://crypto-radar-five.vercel.app)

## اجرا

فقط `index.html` را باز کنید، یا:

```bash
python3 -m http.server 8080
```

دادهٔ زنده از [CoinGecko](https://www.coingecko.com/) و شاخص ترس‌وطمع از [alternative.me](https://alternative.me/crypto/fear-and-greed-index/) می‌آید. اگر شبکه یا محدودیت نرخ مانع شود، ترمینال خودکار به شبیه‌سازی محلی سوییچ می‌کند.

## قابلیت‌ها

- قطب‌نمای لنگر بیت‌کوین و پراکندگی ۱۰۰ دارایی
- امتیاز تکنیکال ترکیبی (RSI، MACD، EMA، بولینگر، مومنتوم) با تعدیل همبستگی نسبت به BTC
- واگرایی قیمت/RSI روی چارت و RSI
- قفل هم‌گرایی ۸ تأیید + استحکام مونت‌کارلو
- بک‌تست walk-forward با حد ضرر ATR، اهداف پله‌ای و سایزینگ کسری‌ثابت
- پرتفوی، دیده‌بان و هشدار قیمت (فقط `localStorage`)
- پالت فرمان (`Ctrl+K` یا `/`)، میانبرها (`?`)، پیوند قابل‌اشتراک `#coin-id`
- نوار «تغییرات این دور» بعد از هر به‌روزرسانی
- تم شب/روز (هماهنگ با سیستم در نخستین بازدید)

## میانبرها

| کلید | عمل |
|---|---|
| `Ctrl/⌘ + K` یا `/` | جست‌وجوی سریع |
| `T` | تم |
| `R` | به‌روزرسانی |
| `J` / `K` | حرکت در جدول سیگنال |
| `Esc` | بستن پنل‌ها |
| `?` | راهنما |

خروجی الگوریتمی است و توصیهٔ سرمایه‌گذاری نیست.
